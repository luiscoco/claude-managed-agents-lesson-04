# Visual continuity

The approved practical apps share a pale blue canvas, white rounded panels, navy typography, blue controls, orange emphasis, the course astronaut, and a large teaching hero. Lesson 4 keeps that layout and four-tab content structure.

All code paths use the same highlight.js formatting helper: API/configuration cards, request/response JSON, conversation code, workflow explanations, setup commands, and the complete SDK example. Model output is parsed, raw HTML discarded, then sanitized; code source is escaped before coloring.

Accessible labels, tab keyboard navigation, persistent text-size preference, visible focus, status announcements, and horizontal scrolling inside code/diagrams support varied devices. Screenshots are captured from the actual scripted demo, not mocked design images.
